Introduction

Bibir script api allows you to add new modules or add new features to some already existing ones

Scripts are written in lua programming language

All script files should be in <MC folder>/bibir/scripts

All scripts are in "scripts" category in ClickGUI

Creating a script

To create a script, make a new .lua file in <MC folder>/bibir/scripts. You can open this folder using .scripts dir command

Open this file in your text editor and create a new local variable (will be called "module variable" below). This variable will contain all event listeners

To add this module, you need to register it in module manager

"script" here is the name of the module

table of all events:

event name event description arguments
on_enable called when the module is enabled none
on_disable called when the module is disabled none
on_tick called before mc.tick() none
on_render called before rendering minecraft vanilla hud none
on_key called on key press/release key (int) action (int, 1 = press, 0 = release)
on_attack called before an entity is attacked by the player targetID
on_kill called when an entity was killed by the player targetID

Player

function name description arguments return type
player.jump() make the player jump (doesn't check for ground) none NIL
player.get_motion() get the player's motion none x, y, z (doubles)
player.set_motion() set the player's motion x, y, z (doubles) NIL
player.message() send message to chat (supports sending minecraft and client commands) text (string) NIL
player.left_click() press left click once none NIL
player.right_click() press right click once none NIL
player.get_position() get player's position none x, y, z (doubles)
player.get_prev_position() get player's previous position none x, y, z (doubles)
player.set_position() set player's position x, y, z (doubles) NIL
player.attack() attack an entity (doesn't check for raycast) entityID (int) NIL
player.set_selected_slot() set selected slot (silent); -1 = unset slot (int) NIL
player.get_selected_slot() get server-side selected slot none slot (int)
player.get_slot() get item in slot (supports inventory slots) (returns NIL if empty) slot (int) item or NIL

World

function name description arguments return type
world.set_timer() set minecraft timer speed timer_speed (double) NIL
world.get_timer() get minecraft timer speed none timer_speed (double)
world.entities() get all entities in world none table of id:entityID
world.get_name() get entity name by id entityID (int) entity_name (string)

world.is_player() check is entity player by id entityID (int) is_player (bool)
world.get_position() get entity position by id entityID (int) x, y, z (doubles)

Module manager

function name description arguments return type
module_manager.register() register a module module_name (string), module NIL
module_manager.is_enabled() is module enabled module_name (string) is_enabled (bool)

Client

function name description arguments return type
client.print() send client message message (string) NIL

Rendering

function name description arguments return type
rendering.get_font() get a font by name (returns NIL if found doesn't exist) font_name (string) Font or NIL
rendering.text() draw text on screen Font, text (string), x, y, scale (doubles), color (int) NIL
rendering.rect() draw rect on screen x, y, width, height (doubles),
radius_top_left (double),
radius_top_right (double),
radius_bottom_right (double),
radius_bottom_left (double),
softness (double), color (int)		 NIL
rendering.rgba_to_int() convert 4 separate values to 1 integer r, g, b, a (ints) color (int)

rendering.text() and rendering.rect() cannot be called outside the on_render event

color format is 32-bit ARGB (8 bits for each channel)
